Saya juga melakukan pengecekan untuk melihat apakah data yang dihasilkan sudah sesuai dengan isi dokumen.

Saya juga mulai menyesuaikan tampilan tabel agar tetap nyaman digunakan ketika jumlah data semakin banyak.

Hari ke-14 (Rabu, 19 Agustus 2026):
Saya menambahkan beberapa fitur pendukung pada Modul Otomasi Data, seperti pencarian dan pengelolaan data. Fitur tersebut dibuat supaya pengguna lebih mudah menemukan data tertentu tanpa harus melihat seluruh data yang ada. Saya juga memperbaiki beberapa bagian tampilan agar lebih mudah digunakan.

Hari ke-15 (Kamis, 20 Agustus 2026):

Hari ini saya menambahkan perhitungan otomatis untuk mengetahui selisih antara stok sistem dan stok fisik. Dengan adanya perhitungan ini, pengguna tidak perlu menghitung selisih secara manual. Saya juga membuat tabel untuk menampilkan data barang beserta jumlah stok dan hasil selisihnya.

Hari ke-18 (Minggu, 23 Agustus 2026):
Saya melanjutkan pengembangan Modul Stok Opname dengan menambahkan fitur pencarian dan filter data. Setelah itu saya melakukan pengujian menggunakan beberapa data barang untuk memastikan fitur dapat berjalan dengan baik.

Hari ke-19 (Senin, 24 Agustus 2026):
Hari ini saya mulai mengerjakan Modul Sales Service. Saya membuat form untuk mencatat data layanan yang diberikan kepada klien. Beberapa data yang dimasukkan seperti nama klien, jenis layanan, tanggal layanan, dan status layanan.

Hari ke-21 (Rabu, 26 Agustus 2026):
Hari ini saya menambahkan fitur untuk mengubah dan memperbarui data pada Modul Sales Service. Pengguna dapat memperbarui status layanan sesuai dengan perkembangan pekerjaan yang sedang dilakukan. Setiap perubahan data kemudian disimpan kembali ke database Supabase.

Hari ke-22 (Kamis, 27 Agustus 2026):
Saya melakukan pengujian terhadap Modul Stok Opname dan Sales Service. Pengujian dilakukan mulai dari proses memasukkan data, menyimpan data ke database, menampilkan data, sampai mengubah data yang sudah tersimpan. Saya juga memperbaiki beberapa kesalahan kecil yang ditemukan selama proses pengujian.
